## Điều hiện đã hoạt động

- Bounded Git runner (`git/runner.rs`): argv cố định, không shell, strip env
  redirect (`GIT_DIR`…), `GIT_TERMINAL_PROMPT=0`, `GIT_PAGER=cat`, timeout
  30/120/300s, `kill_on_drop`, bound output 8 MiB.
- Discovery (`git/discover.rs`): canonicalize + `rev-parse` (toplevel,
  absolute-git-dir, common-dir, bare, object-format). Hỗ trợ `.git` file
  (linked worktree) và mở từ subfolder (dùng chung session theo common-dir).
  Phát hiện và fix bug thật: `--git-common-dir` trả path tương đối theo cwd
  (`.git` vs `../.git`) → anchor vào probe cwd trước khi canonicalize.
- Registry (`services/registry.rs`): session `repoId` opaque (uuid), identity theo
  canonical common-dir, version đơn điệu. Trust mặc định read-only; init là explicit
  intent nên bắt đầu trusted.
- Lệnh IPC: `repo_open/init/close/snapshot/trust_set/recent_list/recent_remove`.
  Snapshot đúng contract (head branch/detached/unborn, counts null cho tới T07).
  Vì `State` + async, commands trả `Result<ApiResult<T>, String>` và registry dùng
  `tokio::sync::Mutex` (guard `std` không `Send` qua await).
- Persistence (`persistence/store.rs`): JSON versioned, atomic temp-write + rename,
  backup khi corrupt, recents tối đa 20, trust key = canonical common-dir.
  Settings file mở rộng ở T14 (migrations).
- UI: Welcome (Open/Init native dialog, Clone disabled T11, recents + Remove, preflight),
  InitModal (branch + confirm, Esc đóng), trust bar, branch label (kể cả detached/unborn),
  Ctrl+O open, Close repo. Dialog import lazy để lỗi plugin không chặn boot.

## Quyết định và thay đổi contract

- `refId` tạm = full ref name cho tới khi token map đầy đủ (T09); `lastFetchAt`/
  `upstream` null cho tới T11; counts null cho tới T07. Không đổi contract.
- `repo_recent_remove` trả `INVALID_ARGUMENT` khi entry không tồn tại (thay vì
  `{removed:false}` im lặng) — trung thực hơn, UI không hiện nút giả.
- Close chưa có busy guard (ghi rõ trong code) — T07 bổ sung cùng job registry.

## Blockers / known issues

  đang dùng, evidence không chứa absolute path repo user, test chỉ dùng `/tmp`.

  workflow verify dùng vite + binary riêng, ổn định. Cần xem lại ở T15.
- Stale vite giữ port 1420 sau session cũ (pid 944478, 22 phút) — đã kill; từ nay kiểm
