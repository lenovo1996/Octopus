## Điều hiện đã hoạt động

- `diff_read` (BE `src-tauri/src/git/diff.rs` + `commands/diff.rs`): targets
  worktree/index/commit; trust-gate worktree/index (`TRUST_REQUIRED`),
  commit là object read nên chạy được ở read-only.
- Path identity là raw bytes qua tokens (worktree/index từ T07 listing, commit
  từ listing mới theo (oid, parent) với marker `c` chống lẫn); display không
  bao giờ round-trip. Token cũ/sai repo/sai loại → `STALE_STATE`.
- `commit_details` giờ trả `pathId` cho từng file (contract §3 yêu cầu); đổi
  parent re-issue tokens, FE drop diff cũ khi đổi parent.
- Engine: unified parser (hunk header, số dòng old/new, marker no-newline),
  binary/symlink/submodule/tooLarge fallbacks, caps 512 KiB / 5000 dòng +
  `truncated`, untracked preview đọc trực tiếp không stage, root dùng
  `diff-tree --root` (empty-tree object không đảm bảo tồn tại), merge đọc đúng
  từng parent OID, unborn index dùng plain `--cached`.
- Tương thích Git 2.43 baseline: phát hiện `diff`/`ls-files` không có
  `--pathspec-from-file`/`--literal-pathspecs` → dùng argv `OsString` (bytes
  chính xác, không shell) + magic `:(literal)` + `--` (đã chứng minh bằng tay:
  `star*.txt` không match `starX.txt`, byte 0xFF round-trip).
- FE: Inspector diff preview thật cho cả 2 tab (click file → load, Back về list,
  Retry khi lỗi, empty "No content changes", no-newline ghi rõ, fallback kinds
  hiện reason). Text render qua Svelte escaping nên HTML/script trong file chỉ
  hiện text. Mock adapter parity (`diffRead` đủ 4 line kinds).

## Quyết định và thay đổi contract

- `CommitFileChange` thêm field cộng thêm `pathId` (tương thích ngược).
- `read_index_diff` bỏ tham số unborn: plain `--cached` đã so với empty tree.
- `read_commit_diff` bỏ `object_format`: root dùng `diff-tree --root`, không
  truyền empty-tree hash (object có thể không tồn tại).
- Runner `run`/`run_with_env` tổng quát hóa sang `AsRef<OsStr>` (callers cũ
  `&[&str]` compile nguyên); không shell, sanitize env giữ nguyên.
- "Expand" ở acceptance được hiểu là xem toàn bộ hunks + cờ truncated (không
  paging từng hunk); "back" là nút Back to files. Mở rộng context từng hunk
  (re-fetch U-full) để dành khi có yêu cầu.
