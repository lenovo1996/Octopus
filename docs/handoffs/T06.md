# T06 handoff — Navigation, branch scope và search

## Làm gì
- `src/lib/search/controller.ts` (mới): `SearchController` latest-query-wins bằng
  generation+seq token. Tauri `invoke()` không có AbortController nên response
  out-of-order bị discard tại client; `invalidate()` khi đổi repo/scope/clear.
- `src/lib/ipc/mock.ts`: thêm `historySearch` literal (subject/author/oid,
  case-insensitive, blank query → trang rỗng), phân trang offset cursor.
- `HistoryPane.svelte`: scope `<select>` (All refs / HEAD / từng ref), search mode
  render list riêng **không** gutter graph (topology không lẫn vào results),
  "Show in graph" từng dòng, Clear, điều hướng phím ArrowUp/Down + Enter,
  focus ring tách khỏi selection, `emptyHint` cho unborn/scope rỗng.
- `Sidebar.svelte`: refs thật từ `repoRefs` (local/remote/tags), click ref → scope
  history; Stashes/PRs/Submodules giữ explanation, không fake count.
- `App.svelte`: state `scope`/`scopeValue`/`refs`, debounce search 250 ms,
  `runSearch` guard kép (token + repoId), `showInGraph` thoát search → allRefs →
  select, sidebar `selectRef`, Escape trong TopBar xóa search.
- `tests/unit/search.test.ts` (mới, 6 tests): out-of-order discard, invalidate khi
  đổi repo, token tăng đơn điệu; mock search literal/phân trang/blank.
