## Điều hiện đã hoạt động

- `merge_start` (`commands/merge.rs`): chỉ từ branch HEAD, tracked-clean, không active operation, không merge đang mở. Source là ref live (local/remote/tag) hoặc OID 40-hex, pin OID trước khi chạy. `--no-ff --no-commit --no-edit`; up-to-date (kể cả source == HEAD) → no-op success; unrelated → refuse; merge fail không unmerged → tự `merge --abort` khôi phục (abort fail thì giữ state + báo, không reset). Record pre-merge HEAD + labels ngoài repo, state Merging.
- `conflict_list/preview`: stages 1/2/3 từ `ls-files -u -z` (quotepath off, byte-exact), phân loại text/addAdd/modifyDelete/binary/symlink/submodule/unsupported; stage thiếu là hợp lệ. Preview base/current/incoming (cap 32 KiB) + working fingerprint (FNV) + labels current/incoming + supportedActions. `canComplete` = MERGE_HEAD còn + hết unmerged; `canAbort` chỉ app-origin (external có abortReason hướng dẫn terminal).
- `conflict_accept` (token `conflict_accept` targets `[pathId, side]` + fingerprint): chỉ text được hỗ trợ, side thiếu stage → refuse (dùng deletion), symlink/non-file refuse, ghi atomic (tmp + rename, không follow symlink), không stage. Validation fail trước khi ghi thì không bump version (giữ token file khác sống).
- `conflict_mark_resolved` (`workingFile` + fingerprint | `deletion` khi file đã mất — backend không bao giờ xóa file; UI hướng dẫn xóa ngoài). Chỉ `git add` đúng 1 path literal.
- `merge_complete` (MERGE_HEAD còn + HEAD đúng + hết unmerged + `stagedReviewed` + identity + subject ≤500/body ≤64KiB): commit qua stdin, verify đúng 2 parents, clear record + state Normal. Mở cho cả external merge.
- `merge_abort` (token `merge_abort`, chỉ app-origin): `merge --abort`, verify HEAD về pre_head, không fallback reset/clean khi fail.
- `confirmation_prepare` mở thêm 2 action (summary nêu tên/path/hậu quả).
- Registry: `merges` map + `status_index_of` (token thay vì path); `build_snapshot` nối `mergeOrigin` (app/external) + tự lành Merging/StashConflict khi marker mất.
- FE: nút Merge trên toolbar, `MergeModal` (chọn source + confirm target HEAD), tab Conflict thật (`ConflictPanel`: list, preview 3 stages, accept 2 bước confirm, mark working/deletion, complete với subject, abort 2 bước confirm, banner app/external). Mock adapter đủ 7 method + confirmations.
- Tests: 11 Rust (clean 2-parents, up-to-date noop, dirty/unrelated/unknown refuse, content full flow accept→mark→complete, stale fingerprint, add/add, modify/delete + deletion, binary/symlink external, abort + token, external abort-refuse/complete-ok, complete-blocked, unreviewed-refuse) + `tests/unit/merge.test.ts` 4 tests mock surface.
