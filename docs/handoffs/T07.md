## Điều hiện đã hoạt động

- `repo_status` (BE `src-tauri/src/commands/status.rs`): trust-gated (`TRUST_REQUIRED`
  khi read-only), đọc `status --porcelain=v2 -z` qua parser byte-level có sẵn,
  trả `ChangedFile[]` với `pathId` opaque `{repoId}:{generation}:{index}`.
- Tokens resolve về raw bytes server-side (`status_resolve`); token cũ generation,
  sai repo, sai shape → `STALE_STATE`. Mỗi lần đọc mới bump generation nên
  external change tự invalidate tokens cũ (test chứng minh).
- Snapshot counts: trusted → staged/unstaged/conflict thật; read-only → null
  ("unavailable until trusted", không zero giả); lỗi đọc degrade về null.
- Coordinator: job registry + `operation_get` (fallback khi miss event) +
  `operation_cancel` (chỉ queued/running → cancelling) + requestId dedup
  (cùng payload trả cùng operation, khác payload → `INVALID_ARGUMENT`) +
  `repo_close` chặn `REPO_BUSY` khi job active + evict caches khi close.
- Per-common-dir write queue: linked worktrees chung common-dir chung một lock
  (test `Arc::ptr_eq` + serialize 8 tasks).
- Events `gitdock://repo-invalidated` (`{repoId, version, reason}`) khi
  snapshot refresh / trust đổi; FE subscribe best-effort + luôn query lại sau
  reconnect (không tin event tuyệt đối).
- FE: Inspector tab Working changes đọc thật (loading/empty/error/Retry,
  trust note, Refresh button, rename `← old`, cờ `· conflict`), `partitionStatus`
  helper (`src/lib/status/partition.ts`), focus-window re-read, mock adapter
  parity (`repoStatus`/`operationGet`/`operationCancel`).

## Quyết định và thay đổi contract

- Không bọc `Versioned<T>` cho `repo_status` (trả `StatusData` trực tiếp như
  `HistoryPage` của T04); version cho mutation lấy từ snapshot. Đúng sibling shape.
- `OperationRecord` tối giản so với spec §5 (chỉ ids/kind/state/stage/progress/
  errorCode, chưa có snapshot/oid result) — đủ cho T07; T09+ mở rộng khi job thật chạy.
- Không thêm OS file-watcher (notify): refresh = focus event + manual Refresh +
  invalidation event. Watcher storm验收 bằng 10 back-to-back reads nhất quán.
- Không đụng repo user; absolute path user không vào evidence.
