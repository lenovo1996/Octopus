## Điều hiện đã hoạt động

- `stash_list` (`commands/stash.rs`): read-only, parse `git stash list --format` (`stashId`, OID, label, `createdAt` epoch). Subject để cuối + `splitn(4)` nên message nhiều dòng không vỡ parse.
- `stash_save` (WriteContext trust/version + per-common-dir queue): tracked-only mặc định, `includeUntracked` explicit thêm `--include-untracked`, không bao giờ `--all` (ignored ở ngoài). Worktree sạch → `{noChange: true, oid: null}` + snapshot (không bump oan). Message ≤500 ký tự qua argv trực tiếp, không shell. Thành công trả OID (`refs/stash`) + snapshot, reset state Normal, invalidate history.
- `stash_apply` (`{stashId, expectedOid, mode: apply|pop}`): validate shape `stash@{n}`, resolve OID ngay trước khi chạy và so với OID UI đã thấy — reorder bên dưới → `STALE_STATE`, không động nhầm entry. Không `--index`. Apply conflict (unmerged entries) → giữ stash + snapshot `stashConflict`. Pop = apply rồi `drop` đúng entry, verify OID đã rời khỏi list; drop thất bại sau apply thành công → partial `{retained: true, dropError}` và không apply lại.
- Registry: `repo_states` map + `set_repo_state`/`state_of` (mặc định Normal, xóa khi close/mutation sạch). Snapshot `state` đã nối sẵn (`stashConflict` serialize đúng cho FE).
- FE: nút Stash/Pop stash live trên toolbar (disable khi readOnly/chưa mở repo), `StashModal` (form save + checkbox untracked + list entries với Apply/Pop, notice cho no-change/conflict/partial, lỗi inline), App reload status + list sau mỗi mutation và giữ snapshot mới. Mock adapter đủ 3 method demo.
- Tests: 5 Rust (tracked-only default + untracked ở lại, include-untracked, no-change, apply-giữ/pop-xóa round-trip, pop conflict giữ stash + state, reorder fail closed) + `tests/unit/stash.test.ts` 3 tests mock surface.
