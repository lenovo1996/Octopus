## Điều hiện đã hoạt động

- `commit_create` (`commands/commit.rs` + `git/commit.rs`): đúng index, message
  qua stdin (`-F -`, thêm runner `run_with_stdin` bounded), subject ≤500 ký tự,
  body ≤64 KiB, chặn EMPTY_INDEX / CONFLICTS_PRESENT / IDENTITY_MISSING /
  TRUST / STALE. Hook/signing fail phân loại HOOK_FAILED/SIGNING_FAILED qua
  stderr (draft giữ nguyên phía client). Trả `{oid, snapshot}`.
- `identity_read`: name/email/scope (local/global/system/command/multiple/
  missing) + signing flag, không secrets.
- `branch_create` (+switch option, partial `switched`/`switchError`),
  `branch_switch` (local + remote kèm explicit new name, DIRTY_WORKTREE,
  checked-out-elsewhere, current no-op), `branch_delete` sau
  `confirmation_prepare` (token single-use TTL 60s bind repo/version/action/
  targets, fail closed). Delete chỉ `-d`, unmerged/current/elsewhere refuse.
- Queue per-common-dir + version bump + `invalidate_history` sau mọi mutation.
- FE: footer commit editor (subject + body, identity line, detached warning,
  lỗi giữ draft, success clear draft+selection), nút Branch ở toolbar mở
  BranchModal (create/switch/track/delete 2 bước với Cancel mặc định),
  mock adapter có index/branches/confirm in-memory.
