## Điều hiện đã hoạt động

- `remote_status` (`commands/sync.rs`): read-only, không chạm network — effective upstream, ahead/behind, `lastFetchAt` ISO-8601. Không upstream → field None, không lỗi.
- Jobs fetch/pull/push: executor mới `execute_remote` (spawn `git --progress`, stderr piped, forward % qua channel, kill khi `AtomicBool` cancel, bounded `NETWORK_TIMEOUT`). `run_remote_job` relay progress + poll cancel flag mỗi 200ms qua `tokio::select`, terminal → job registry + redacted log row + `repo-invalidated` khi ok. Push chỉ normal (không force/lease/mirror/all); pull `--ff-only`; dirty/diverged pull không đổi files (git từ chối, job Failed + classify).
- URL redaction trong mọi summary/log (`redact_url`), secrets không log.
- `operation_log`: append-only theo repo, cursor paging, entries `{seq, at, kind, summary, outcome, errorCode}`.
- FE: toolbar Fetch/Pull/Push live (disable khi readOnly/chưa mở repo/đang có job), label `origin/main · ↑1 ↓2` + tooltip URL/last-fetch, job label + Cancel, lỗi inline, panel "Sync log" (newest-first). App track job qua event `gitdock://operation` + poll `operationGet` 600ms fallback; terminal success → snapshot/history/status/remote/log refresh. Mock adapter có đủ 5 method demo.
- Tests: 5 Rust mới (`execute_remote` ok/fail/cancel/progress + round-trip push→bare→fetch giữa 2 clones local, fixtures `/tmp`); `tests/unit/sync.test.ts` 4 tests mock surface.
