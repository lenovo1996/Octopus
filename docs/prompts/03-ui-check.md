# Prompt review độ bám giao diện

---

Kiểm UI GitDock so với example.webp, docs/02-ux-ui-spec.md và ba wireframes trong docs/design. Đọc/nhìn ảnh trực tiếp; không review theo trí nhớ.

Mở app hoặc preview được project hỗ trợ và kiểm Working changes, Commit details, Merge conflict tại 1440×900 và 1280×800. Với preview mock, ghi rõ đây là UI evidence, không phải Git behavior đã pass. Kiểm topbar/toolbar, sidebar, graph, inspector, status bar; row density, lane alignment, text contrast, resize, keyboard, empty/loading/error, Planned/Read-only labels.

Nếu công cụ/môi trường không chụp hoặc mở native app được, nêu giới hạn cụ thể; không tạo screenshot giả hay lấy wireframe làm evidence implementation. Lưu screenshots thực vào docs/evidence/task hiện tại khi phù hợp.

Báo tối đa 5 nhóm vấn đề ưu tiên với vị trí UI và sửa đề xuất; kết luận pass/fail theo rubric. Không đổi UI thành dashboard/card layout khác ảnh mẫu. Kết thúc bằng một hành động sửa cụ thể dưới 2 phút.
